## P0 — Must fix before production use

| # | Requirement | Acceptance |
|---|-------------|------------|
| R1 | **Complete Kill Switch** | Emergency stop invalidates PIN, kills active subprocesses, old PIN returns 401 |
| R2 | **Audit log completeness** | Client IP on connect + tool calls; `agent_connected` event; status `SUCCESS`/`ERROR` |
| R3 | **`read_text_file` default tail** | Omitting `tail_lines` → last 200 lines; explicit `0` → no tail limit |

## P1 — Needed for daily IT workflow

| # | Requirement | Acceptance |
|---|-------------|------------|
| R4 | **Network in system overview** | `local_ips`, `dns_servers`, `default_gateway` in JSON |
| R5 | **PIN / port rotation UI** | Button regenerates PIN; optional port rebind; MCP config updates |
| R6 | **Session restart** | After stop, "重新开始协助" starts new session without restarting app |
| R7 | **Cursor E2E gate** | 7-step manual checklist passes on Windows before v0.2.0 tag |
