# at-pc v0.2 Gap Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close all 6 critical functional and security gaps identified in the v0.1 review to make at-pc production-ready for real-world LAN IT remote troubleshooting.

**Architecture:** Upgrade `AppState` with mutable thread-safe PIN storage and a global `ProcessRegistry` for bulletproof Kill Switch execution. Enhance Axum router and handlers to capture client IP on `/sse` and `tools/call`. Extend `get_system_overview` with cross-platform DNS, gateway, and local IP detection. Add PIN rotation and in-app session restart to the `egui` desktop interface.

**Tech Stack:** Rust 2021, `eframe` / `egui`, `tokio`, `axum`, `sysinfo`, `local-ip-address`, `xcap`, `serde`, `serde_json`.

**Spec:** [`docs/superpowers/specs/2026-09-01-at-pc-v0.2-gap-closure-design.md`](file:///Users/clkj/项目/at/docs/superpowers/specs/2026-09-01-at-pc-v0.2-gap-closure-design.md)

## Global Constraints

- Must maintain standalone single-binary delivery with zero external runtime requirements (no Node.js, Python, or WebView2).
- Must enforce non-blocking, non-interactive command execution with strict timeout controls.
- All HTTP / SSE requests must strictly authenticate against the live PIN (and fail immediately when stopped).
- All unit and integration tests must pass cleanly on macOS, Linux, and Windows.
