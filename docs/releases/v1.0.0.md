## 🌟 概述

我们非常高兴地宣布 **at-pc 首个正式版本 v1.0.0** 正式发布！🎉

`at-pc` 是 AT (Antigravity Terminal) 系列专为现代 AI Agent 与远程桌面运维打造的高性能远程终端与控制网关，采用 **纯 Rust** 研发。本项目深度结合 **C/S 分布式解耦架构**、**原生 Model Context Protocol (MCP)** 以及 **Computer Use / 视觉增强技术**，为 LLM/VLM（如 Claude 3.5 Sonnet、Cursor、AT-OpsAgent）提供安全、可审计、毫秒级响应的系统级操控能力。

---

## 🚀 核心特性与亮点

### 1. 现代化 C/S 分布式控制架构
- **解耦设计**：模块拆分为 `at-pc-protocol`（共享协议帧与模型）、`at-pc-server`（中心网关与 MCP 路由）、`at-pc-agent`（受控端守护程序）及 `at-pc-desktop-core`（底层跨平台桌面交互引擎）。
- **高并发双向信令**：基于 WebSocket (TLS/mTLS) 的轻量级通信通道，具备动态心跳探活（5s 间隔）、异常离线平滑感知（Sweep）与客户端自动指数退避重连。
- **内置 Web 管理控制台**：`at-pc-server` 内嵌现代化单页控制面板，支持查看已连接终端、实时多物理屏幕推流预览、终端重命名及在线状态监控。

### 2. 原生 MCP 支持与动态跨终端路由
- **标准协议全覆盖**：原生支持 Model Context Protocol (MCP)，同时提供用于 Cursor / 本地 IDE 的 `stdio` 模式，以及用于分布式智能体调用的 HTTP / SSE 网关。
- **39+ 项系统级与具身操作工具**：涵盖屏幕捕获、鼠标键盘模拟、进程生命周期管理、文件读写、Windows 服务启停、网络配置以及终端元数据治理。
- **智能会话级路由**：支持基于上下文的会话绑定、指定目标终端执行（`target_terminal`）与自动故障转移。

### 3. 全能力 Computer Use 与视觉/语义增强
- **多物理显示器无缝支持**：支持跨平台多屏幕自动枚举、指定物理屏幕（`display_index`）截图与高质量推流，彻底解决多屏办公与运维场景的定位漂移问题。
- **Set-of-Marks (SoM) 视觉标记增强**：对截屏内容自动执行标记定位，极大提升视觉模型（VLM）点击决策精度；支持智能网格降采样与坐标无损反向映射。
- **Windows UI Automation (UIA) 深度语义解析**：实时获取当前窗口层次与控件语义树，结构化快速定位目标输入框与按钮。
- **macOS 原生 Cocoa 窗口审查**：微秒级（0.26ms）前台窗口层级与元数据提取。
- **具身操作模拟**：支持单点点击、相对/绝对移动、拖拽、文本输入与复杂组合按键序列。

### 4. 极致性能工程与低延迟流控
- **64-bit 词宽哈希变化检测**：在 1080p 分辨率下实现 **0.48 ms** 超高速脏块变化检测（相比逐字节检测提速 2.5x+），静态桌面大幅降低 CPU 负载与网络占用。
- **截屏 Payload 锐减 70%+**：引入默认 1280 规格自适应降采样算法，网络传输体积由 360KB 下降至 106KB（JPEG）甚至 72KB。
- **进程列表 TTL 缓存**：引入 1000ms 自适应热缓存，高频连续查询响应从 70ms 降低至 **5~8ms**（提升 13x - 15x）。
- **5000+ 级大规模终端扩展性**：终端注册中心采用 `Arc/COW` 并发优化，在大规模并发下仍保持 O(1) 更新时延。
- **硬性 CI 性能门禁**：内置自动化性能基准探针与阈值校验器（`thresholds.toml`），确保后续迭代零性能衰减。

### 5. 企业级安全准入与全生命周期审计
- **具身操作安全阀门 (`enable_computer_use`)**：客户端默认禁用模拟鼠标键盘输入，必须通过参数显式开启，从源头杜绝未授权具身操作。
- **不可篡改审计流水**：服务端与客户端双重落盘记录审计日志（JSONL 格式），高频无害事件（如持续 MouseMove）智能过滤，关键指令全量留存。
- **双向安全加密**：支持 TLS 1.3 / WSS 传输层加密与 mTLS 客户端证书双向校验。
- **紧急制动 (Emergency Kill Switch)**：客户端桌面界面配备一键紧急断开，可瞬间阻断所有远端控制通道并注销会话。

## ⚡ 快速上手指南

### 1. 部署与启动服务端 (Server)

```bash
# 启动服务端网关 (默认监听 127.0.0.1，MCP 端口 9800，WebSocket 端口 9801)
./at-pc-server-macos --host 0.0.0.0 --ws-port 9801 --mcp-port 9800

# 访问内置 Web 管理面板
open http://localhost:9800/
```

### 2. 部署与连接受控端 (Agent)

```bash
# 启动受控端 Agent (默认连接本地服务端，开启 Computer Use 具身操作能力)
./at-pc-agent-macos --server ws://<服务端IP>:9801/ws --enable-computer-use

# Windows 后台服务模式
at-pc-agent.exe --server ws://<服务端IP>:9801/ws --headless --enable-computer-use
```

### 3. 接入 Cursor / Claude Desktop (MCP 配置)

在 Cursor 或 Claude Desktop 的 MCP 配置文件中添加：

```json
{
  "mcpServers": {
    "at-pc": {
      "command": "/path/to/at-pc-server-macos",
      "args": ["--stdio"]
    }
  }
}
```

或者通过 HTTP / SSE 模式接入：
```json
{
  "mcpServers": {
    "at-pc": {
      "url": "http://127.0.0.1:9800/sse"
    }
  }
}
```
